# 小喷 for Mac · XiaoPen

原生 macOS 菜单栏语音助手。通过麦克风与 Apple Speech 转写语音，匹配自定义唤醒词，在本机执行系统音量指令；其他问题发送到 Ollama、Anthropic 或 OpenAI 兼容接口，并用本机 Qwen3-TTS 或系统语音朗读回复。当前项目是独立的 Mac 应用，没有 ESP32 通信模块。

要求 macOS 14+；开发使用 Swift 6 与 SwiftUI。应用名称暂时保留“小喷”，图标采用选定的小抱枕形象。

## 安装与运行

```bash
# 测试（不需要麦克风或真实模型密钥）
swift test

# Release 构建、组装 .app、本地签名、创建 DMG
./scripts/build_app.sh

# 也可直接安装；如果已安装，先备份旧版本
./scripts/build_app.sh --install /Applications
open /Applications/XiaoPen.app
```

默认只保留 `build/XiaoPen-1.0.6.dmg`；DMG 创建失败时脚本会生成 ZIP。用于打包的 `.app` 保存在隐藏临时目录，完成后清理，避免系统搜索显示多个同名应用。`--skip-build` 复用已有 Release，`--keep-app` 显式保留 `build/XiaoPen.app`，`--no-dmg` 仅生成并保留应用，`--help` 查看全部选项。旧版本备份应压缩保存；日常运行使用 `/Applications/XiaoPen.app`。

签名默认自动选择本机唯一有效的 Apple Development 证书；没有此类证书、存在多个候选或无法读取身份时，脚本会明确提示并退回 ad-hoc 签名。可用 `--sign-identity` 指定证书 SHA-1 哈希或完整名称，`--sign-identity -` 显式使用 ad-hoc。指定证书不可用时打包失败，不会悄悄降级。证书签名保留 `codesign` 自动生成的身份要求，让后续代码变更仍能被系统识别为同一应用；ad-hoc 的身份随代码版本变化，可能反复要求麦克风、语音识别或钥匙串授权，详见 [Apple 签名身份说明](https://developer.apple.com/documentation/technotes/tn3127-inside-code-signing-requirements)。首次从 ad-hoc 切换到证书签名可能需要重新授权。系统若询问能否使用签名私钥，需要本人确认；脚本不会修改证书信任、隐私授权或钥匙串访问策略。安装包尚未经过 Developer ID 公证。

首次启动请允许麦克风与语音识别权限，并在系统设置 → 键盘 → 听写中开启普通话（中国大陆）。系统语音服务被关闭或缺少语言资源时，应用会暂停采音并提供听写设置与重新检测入口；不会继续显示可用的语音待命。应用常驻菜单栏，没有主窗口；点击菜单栏图标打开偏好设置。Mac mini 通常需要外接麦克风。缺少设备、权限或识别服务时，菜单和悬浮窗会提示原因；可在“语音与唤醒”里进入系统权限页并重新检测。

## 模型配置

- **本地 Ollama**：启动 Ollama，填写服务地址（默认 `http://127.0.0.1:11434`）和已安装的对话模型（默认 `qwen2.5:latest`）。
- **Anthropic**：填写 API Key 和可用模型，默认 `claude-sonnet-4-6`。旧版本的默认 `claude-3-5-sonnet-latest` 会自动迁移，其他自定义模型保持不变。
- **国内平台预设**：“当前大脑”可直接选择千问 AI 平台、DeepSeek、Kimi、MiniMax，自动填入接口地址和推荐的快速模型（可在“常用”菜单切换或手动填写）。每个平台的地址、模型和密钥分别保存，切换平台不会丢失配置。

  | 平台 | 默认 Base URL | 推荐模型 | 关闭深度思考的方式 |
  | --- | --- | --- | --- |
  | 千问 AI 平台 | `https://maas.qianwenaiapi.com/compatible-mode/v1` | `deepseek-v4.1-flash` | `enable_thinking: false`（DeepSeek V4、Qwen3、Kimi K2.5/K2.6/K3 等混合思考模型） |
  | DeepSeek | `https://api.deepseek.com/v1` | `deepseek-v4-flash` | `thinking: {type: disabled}` |
  | Kimi | `https://api.moonshot.cn/v1` | `kimi-k2.6` | `thinking: {type: disabled}`（仅 K2.5/K2.6，K3 与 code 系列总是思考） |
  | MiniMax | `https://api.minimaxi.com/v1` | `MiniMax-M2.7-highspeed` | M3 使用 `thinking: {type: disabled}`；并始终发送 `reasoning_split`，思考内容不会被朗读 |

  扩展参数按 Base URL 的实际域名发送，只发给已知支持的模型，避免不支持的模型直接拒绝请求。所有平台返回的 `<think>…</think>` 推理文本都会被过滤，不显示也不朗读。
- **自定义 OpenAI 兼容接口**：填写 Base URL、模型和密钥，例如官方 `https://api.openai.com/v1` / `gpt-4o-mini`。自建无鉴权服务可留空密钥。

配置完成后确认“当前大脑”已选择相应平台；悬浮窗会显示实际平台与模型。升级前已经配置的接口会按域名自动归入对应平台，原有密钥继续使用。

密钥停止输入后保存到 macOS 钥匙串，保存失败会在设置中提示。密钥读取在后台进行，可取消且有超时；需要授权时点击“读取已有密钥”，不会把读取失败当作空密钥提交。连接测试实际请求模型元数据，检查服务、鉴权及所填模型；它不执行推理，不能保证账户余额或每种推理功能均可用。401、429、模型缺失与流中服务错误都会给出提示。

## 唤醒与对话

在“语音与唤醒”中设置自己的唤醒词，例如“你好搭子”。首次使用默认“小喷小喷”，已有设置会保留。唤醒词与应用名称无关，只匹配配置的词；忽略大小写、全半角、空格与标点，空白或纯标点不会唤醒。

开启语音唤醒时，待命持续采音并进行转写。识别到唤醒词后保留同一录音和识别会话，连续说“唤醒词 + 问题”不会因切换会话丢掉后半句。仅新转写文字会延长倾听；默认停顿 1.2 秒后给系统最多 0.6 秒完成最终转写，再提交；句子以“吗/呢/？”结尾或已识别为音量、提醒指令时只等 0.7 秒，背景噪音不会不断延后发送。关闭后待命停止采音，仍可从菜单手动唤醒。处理模型回复与朗读期间暂停麦克风，避免听到自己的回复；使用菜单或悬浮窗的“打断”按钮中断请求和朗读。语音打断尚未实现。

语音识别使用系统本机中文识别；本机识别不支持或语言资源缺失时会给出提示，仍可使用文字对话。唤醒基于转写后的文本匹配，没有专用关键词模型。悬浮窗在待命时显示唤醒词和“刚刚听到”的文字，可用“直接说话”跳过唤醒词。音量为零时波形不再模拟麦克风输入。

识别任务结束或出错后会自动续接，失败时使用有上限的重试间隔。无音频、输入中断或持续有声音但没有转写时会给出提示并重启本机识别，连续三次仍失败时等待手动“重新检测”。监听系统默认输入设备变化，设备断开后会等待恢复；手动关闭采音会停止自动重试。采音使用普通输入，避免蓝牙耳机的语音处理聚合设备异常；处理和朗读回复时暂停麦克风。

回复文本流式显示；第一句在出现第一个够长的逗号分句时就开始朗读，之后按完整句子朗读；生成与朗读可以同时进行，最后一句播完后返回待命。支持关闭思考的平台和模型默认使用快速回复，设置中可重新开启深度思考。唤醒时应用会预先建立到模型服务的连接，减少首字等待。

语音回答结束后默认继续倾听 6 秒，可以直接追问，不用再说唤醒词（设置 → 技能 → 对话体验，可调整或关闭）。文字输入不会触发继续倾听。

每次请求都会附带当前日期、时间、星期和设置的城市，只附加在本次问题上，不写入系统提示词，便于平台复用前缀缓存。长回复可以滚动和复制。最近最多 6 轮完整对话（合计不超过 12,000 字符）只保存在内存中，退出、清空或更换模型配置/提示词后清除。

## 系统音量

语音和文字都可以直接控制当前默认输出设备。例如“音量调到百分之四十”“音量调大一点”“音量减少10个百分点”“静音”“取消静音”“当前音量是多少”。未指定幅度时，调大/调小一点默认改变10个百分点；静音保留原音量，取消静音恢复原值。

指令由本机识别并通过 CoreAudio 执行，不调用聊天 API，也不依赖模型的工具调用能力。每次操作后重新读取设备状态，只有读回确认后才显示“系统操作”结果。否定、引用、转述和混合多步骤请求不会触发写入；百分比只接受0–100的整数。静音或音量为零时仅显示文字确认，并恢复语音待命。

HDMI、部分USB和数字音箱没有向macOS公开音量或静音属性时，会提示不支持；应用不会假报成功，也不会自动切换输出设备。这类设备需要在显示器/音箱上调节，或在系统声音设置中选择支持调节的输出。设备在操作中切换、写入失败或没有确认变化时同样会给出失败提示。

## 天气

问“今天天气怎么样”“明天会下雨吗”“北京后天冷不冷”时，应用先从 [Open-Meteo](https://open-meteo.com) 获取实时天气和三天预报，再交给模型组织成口语回答。数据源无需 API Key，只收到城市名和坐标。城市优先级：问题里提到的城市 → “设置 → 技能 → 天气”中的固定城市 → 自动定位。自动定位默认开启，使用 macOS 定位服务（Mac 主要靠附近的 Wi-Fi），首次启动会请求定位权限；只取城市和约 1 公里精度的坐标，不保存位置记录，也不使用第三方 IP 定位。无法定位时会请你说出城市。说话过程中一旦听出是天气问题就开始查询，结果缓存 10 分钟；查询失败时模型会如实说明，不会猜测。

## 提醒与计时

提醒和计时由本机直接解析并执行，不依赖模型的工具调用能力，也不额外请求模型，所以几乎立即确认。例如：

- “十分钟后提醒我关火”“一个半小时以后叫我”“定一个五分钟的计时器”
- “明天早上八点叫我起床”“下午三点半提醒我开会”“下周一上午十点提醒我交报告”
- “我有哪些提醒”“取消关火的提醒”“取消所有提醒”

只说“提醒我喝水”时会追问时间，接着说“十分钟后”即可。提醒到点会播放提示音、朗读内容并在悬浮窗显示，可点“知道了”或“5 分钟后再提醒”，也可以直接说“再过五分钟”。正在对话时到点的提醒会等这一轮结束再播报。提醒保存在 `~/Library/Application Support/XiaoPen/reminders.json`，重启后仍有效；应用未运行期间到点的提醒会在下次启动时补报。安装包运行时还会发送系统通知（首次创建提醒时请求通知权限）。

## 本机自然语音

推荐 Qwen3-TTS-12Hz-1.7B-CustomVoice 的 MLX 8-bit 版本。模型约 3.1GB，使用 Apple Silicon GPU，通过随应用打包的原生 Swift 组件运行；无需 Python 推理服务、云端语音接口或额外语音 API Key。首次加载后保持模型就绪。模型与安装包分开保存，不增加同名应用。

安装或校验模型：

```bash
python3 scripts/setup_local_voice.py
python3 scripts/setup_local_voice.py --verify-only
```

Hugging Face 大文件下载较慢时可加 `--source modelscope`。两种来源都逐文件校验固定 Hugging Face 版本的 SHA-256 / Git blob 摘要；校验失败的文件不会安装。模型目录为 `~/Library/Application Support/XiaoPen/Models/Qwen3-TTS-12Hz-1.7B-CustomVoice-8bit`。

设置 → 语音与唤醒 → 回复语音，可选本机 Qwen3-TTS、Serena/Vivian/福叔/北京或四川音色，自定义说话风格并试听。系统语速滑块只作用于系统朗读；本机模型根据风格指令控制表达。模型未准备好或输出设备变化时给出明确错误，回答文字仍保留。

首句文字完成后开始生成音频，音频按块播放；文字生成结束和最后一块音频实际播完均满足后才恢复麦克风。打断会立即停止播放并结束本机推理进程，避免旧语音混进新回复；下次重新加载。麦克风转写仍使用 Apple 本机识别，回答模型仍使用原有配置。模型来源与实测见 [本机语音说明](docs/voice/local-tts.md)。

悬浮窗底部也可以直接输入文字并回车发送，不需要麦克风或语音识别权限，便于先测试模型连接和回复。

菜单提供手动唤醒、打断、显示悬浮窗、清空对话、设置和退出。全局快捷键 `⌥⌘K` 在任何应用中可用：待命时开始说话，倾听时立即发送，回复时打断（设置 → 技能中可关闭）。菜单快捷键 `⌘⇧K`、`⌘,`、`⌘Q` 需要应用或菜单处于活动状态。待命时“刚刚听到”的转写默认不再显示，可在设置中打开。

## 当前验证范围

自动测试覆盖唤醒词匹配与持久化、模型默认迁移、平台预设与密钥迁移、各平台思考参数、推理标签过滤、提醒解析与持久化、天气意图与报告格式、端点检测与首句切分、钥匙串读写、会话过期回调、重试退避、对话上下文及通过 Mock 网络验证的服务连接、错误流与取消行为。真实麦克风、长时间语音待命、热插拔和声学效果仍需在安装后的应用中试用。
