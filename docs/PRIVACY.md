# 小喷隐私说明

更新日期：2026 年 10 月 11 日

小喷是一个开源的 macOS 应用，没有自己的服务器，也不收集任何统计数据。下面说明哪些数据会离开你的 Mac、发往哪里。

## 留在本机的数据

| 数据 | 说明 |
| --- | --- |
| 麦克风声音 | 由 macOS 本机语音识别处理（应用强制要求本机识别，不会回退到苹果云端识别）。录音不保存、不上传。 |
| 对话记录 | 最近 6 轮只保存在内存里，退出、清空或更换模型后清除。 |
| 提醒 | 保存在 `~/Library/Application Support/XiaoPen/reminders.json`。 |
| API Key | 保存在 macOS 钥匙串中。 |
| 自然语音模型 | 保存在 `~/Library/Application Support/XiaoPen/Models/`，在本机 GPU 上运行。 |
| 日志 | 写入 macOS 系统日志，不包含对话内容、识别文字或密钥。 |

## 发送到第三方的数据

| 发送给 | 发送什么 | 什么时候 |
| --- | --- | --- |
| 你选择的大模型平台（千问 AI 平台、DeepSeek、Kimi、MiniMax、OpenAI 兼容接口、Anthropic 或本地 Ollama） | 唤醒后识别出的文字、最近几轮对话、当前日期时间和所在城市、人设提示词 | 每次需要模型回答时。音量和提醒指令在本机执行，不发送。 |
| Open-Meteo（open-meteo.com） | 城市名或约 1 公里精度的坐标 | 问天气时 |
| 苹果定位服务 | 由 macOS 处理，用于得到所在城市 | 开启自动定位时，最多每 30 分钟一次 |
| GitHub | 一次版本查询请求，不含个人信息 | 每天最多一次检查更新 |
| ModelScope 或 Hugging Face | 模型文件下载请求 | 只在你下载自然语音模型时 |

各模型平台如何处理你发送的文字，以该平台的隐私政策为准。

## 权限

- **麦克风、语音识别**：听见并在本机识别你说的话。
- **定位（可选）**：查天气时自动确定城市。拒绝后可以在设置里填写固定城市。
- **通知（可选）**：提醒到点时显示系统通知。
